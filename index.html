📖 USER GUIDE

📍 1. Choose Location required

  • Quick Region: Use dropdown for broad area
  • Precise Map: Click map or use "My Location" for exact coordinates
  • Toggle Switch: Use "Switch to Map/Quick" button to change modes
  • When using map, dropdown shows "📍 Map in use"
  • Both methods store region + coordinates

👤 2. Observer Name required · persists

  • Enter your name (compulsory field)
  • Name is saved and will auto-fill next time

📅 3. Date required

  • Select collection date
  • Month auto-updates weather display

🌼 4. Flowering Stage required

  • Check all that apply, or check "None" if no flowering observed
  • At least one stage or "None" must be selected

🐝 5. Pollinators required

  • Check all observed pollinators (insects + birds)
  • Or check "None" if no pollinators observed
  • "Other" field for additional species

🌡️ 6. Weather Data optional · auto-load

  • Auto-load weather: Click "🌤️ Auto-load Current Weather" button
  • Uses Open-Meteo (free, no API key required)
  • Automatically loads when you click the map or use "My Location"

🌱 7. Seed & Fire optional

  • Seed maturity
  • Fire history
  • Site notes for additional observations

💾 8. Save, Export & Share

  • 💾 Save: Store in browser - records appear below
  • 📄 Export All to CSV: Download all data as CSV file
  • ✅ Export Selected to CSV: Download only checked records
  • 📂 Import CSV: Load previously exported CSV files
  • 📧 Email Data as CSV: Send CSV data directly via email
  • ✏️ Manage: Edit or delete existing records
